# 3-Tier Task Management System

## Architecture
Browser
   ↓
React + Nginx
   ↓
Spring Boot
   ↓
MySQL

## Tech Stack
React, Vite, Nginx
Spring Boot, Java
MySQL
Docker, Docker Compose

## Features
- Create tasks
- View tasks
- Delete tasks
- Persistent MySQL storage
- Containerized frontend/backend/database
- Healthcheck-based service startup

## Run
docker compose up -d
